# 歌曲段落設計-MV拍攝小幫手

由光影哲學設計有限公司設計 · 製片：光哲設計

載入歌曲、用秒數設定段落並以 Pad 播放，搭配同步歌詞（LRC／貼歌詞自動對時）、每段倍速、預備拍、淡出與 MP3 輸出。

這是 PWA 網頁 App：用手機瀏覽器打開網址後「加入主畫面」，就能像 App 一樣全螢幕開啟，第一次開過之後沒有網路也能使用。

- `index.html`：整個 App（單一檔案，內含 MP3 編碼器 lamejs 1.2.1，LGPL）
- `sw.js`：離線快取
- `manifest.webmanifest`、`icon-*.png`：App 名稱與圖示
